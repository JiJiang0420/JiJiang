# 项目实践

尚未收录已完成原型。这里用于连接学习资料与真正做出的东西。

建议从“单场景收集游戏”开始：移动角色，收集少量物品，显示进度，到达目标后可以重新开始。目标平台、引擎与版本在创建项目时明确记录。

每个项目建立独立目录，至少记录：

- 目标：希望验证哪一个玩法或技术问题。
- 范围：本次必须实现的功能与暂缓的功能。
- 运行：引擎版本、操作方式、构建步骤。
- 结果：完成情况、试玩反馈、已知问题。
- 复盘：使用[项目复盘模板](../templates/project-review.md)。

引擎项目应有合适的 `.gitignore`；缓存、临时构建与大型素材不要直接混入资料目录。
