# Kenney · 学习指南

- 入口：[官方站点 / 原始资料](https://kenney.nl/assets)
- 适合：需要快速搭建原型的占位场景、角色或 UI。
- 学习状态：待学习、待实践；以下是练习建议，并非已完成记录。
- 外链状态：尚未逐个联网核验；使用时记录访问日期与适用版本。

## 建议学习顺序

1. 按 2D、3D 或 UI 筛选资源包。
2. 阅读包内说明和许可。
3. 检查尺寸、比例、格式和风格。
4. 导入少量资源验证。
5. 记录来源与改动。

## 动手练习

选一个资源包，仅用同一套素材搭建小场景，并制作可交互按钮。

## 完成标准

资源比例与碰撞范围合理；UI 可读；记录资源包名称、下载页、许可及实际使用文件。

## 注意事项

以具体资源包附带许可为准；不要根据站点名推断所有内容的授权，也不要把付费工具与素材包混为一谈。

## 留下学习记录

复制[学习笔记模板](../../templates/learning-note.md)，记录使用版本、实际步骤、输出或截图、遇到的问题与解决证据。将新笔记加入[笔记索引](../../notes/README.md)。未执行的步骤保留待办状态。
