## 建议学习顺序

1. 变量、类型与控制流。
2. 方法、类、属性与访问控制。
3. 集合、泛型与异常。
4. 委托、事件与接口。
5. 理解引用与值类型后再学习异步。

## 动手练习

实现纯逻辑背包：添加物品、合并数量、移除物品，并拒绝负数或库存不足的操作。

## 完成标准

覆盖添加、合并、删除最后一件和非法输入；操作失败时库存保持一致；记录实际输出。

## 注意事项

Unity 支持的 C# 与 .NET 特性取决于编辑器和运行环境。不要把 async 用作所有问题的默认方案；注意游戏对象 API 的线程限制。
