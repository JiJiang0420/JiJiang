# itch.io 开发者文档 · 学习指南

- 入口：[官方站点 / 原始资料](https://itch.io/docs/creators/)
- 适合：准备给他人试玩原型，需要整理页面与构建文件。
- 学习状态：待学习、待实践；以下是练习建议，并非已完成记录。
- 外链状态：尚未逐个联网核验；使用时记录访问日期与适用版本。

## 建议学习顺序

1. Creator 文档与项目页面。
2. 平台与上传文件配置。
3. 可下载构建与 HTML 游戏要求。
4. 可见性、页面说明与截图。
5. 更新流程和试玩反馈。

## 动手练习

先在本地准备发行包与页面文案，写明平台、操作、当前版本和已知问题；按需要在账号中建立非公开测试页。

## 完成标准

从干净目录解压可运行；依赖文件齐全；页面操作说明与实际一致；若进行非公开测试，检查访问权限。

## 注意事项

账号、上传与发布是独立操作，本指南没有执行。HTML 游戏有特定打包和运行限制；价格与分发条件以平台当前说明为准。
