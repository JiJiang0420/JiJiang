# 工具

共 9 项。按资源本身的主要用途分类；软件手册仍属于学习资料，软件本体属于工具。

## 策划与设计

- [Twine 互动叙事](guides/twine.md) · [原始入口](https://twinery.org/)：通过节点和链接制作互动故事，练习分支、条件与叙事反馈。
- [Machinations 系统与数值设计](guides/machinations.md) · [原始入口](https://machinations.io/)：用资源流与系统图分析游戏经济，探索产出、消耗、反馈和增长。
- [LDtk 2D 关卡编辑器](guides/ldtk.md) · [原始入口](https://github.com/deepnight/ldtk)：制作 2D 关卡，配置实体、图块与关卡数据。
- [Tiled 地图编辑器](guides/tiled.md) · [原始入口](https://github.com/mapeditor/tiled)：编辑图块地图、对象层与自定义属性。

## 美术与素材

- [Pixelorama 像素美术工具](guides/pixelorama.md) · [原始入口](https://github.com/Orama-Interactive/Pixelorama)：制作像素角色、图块与逐帧动画。
- [Blender 3D 创作工具](guides/blender-tool.md) · [原始入口](https://github.com/blender/blender)：建模、绑定、动画与渲染等 3D 内容创作。

## 引擎与编程

- [Godot Engine 编辑器](guides/godot-tool.md) · [原始入口](https://github.com/godotengine/godot)：用于创建、运行和导出 2D 与 3D 游戏的引擎编辑器。
- [DirectX Tool Kit for DirectX 11](guides/directxtk.md) · [原始入口](https://github.com/microsoft/DirectXTK)：用于 Direct3D 11 C++ 项目的辅助库，包含常用图形与音频组件。

## 音频与音效

- [Audacity 音频编辑器](guides/audacity-tool.md) · [原始入口](https://github.com/audacity/audacity)：多轨录音与音频编辑，适合剪辑音效和录音。
