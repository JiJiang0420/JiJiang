# 游戏开发资源索引

共 5 个通用分类、14 项学习资源，每项均有独立指南，包含学习顺序、练习任务、完成标准和注意事项。另设个人定制工具目录。当前均为“已收藏、待实践”，外链尚未逐个联网核验；工具版本、费用和具体素材许可应在使用时确认。

## 怎么开始

先从 Unity、Godot、Unreal 中选择一个引擎，配合 Git 建立最小项目。Unity 路线同时学习 C#。完成核心循环后，再按项目需要学习架构、Shader、美术与音频。发布资料用于准备发行流程，不要求现在注册或发布。三个引擎无需同时学习。

推荐路径：[学习路线](../docs/learning-roadmap.md) → 选择引擎指南 → 原型练习 → [学习笔记](../notes/README.md) → 发布准备。

个人项目工具集中整理在[定制工具目录](../custom-tools/README.md)，已为哼鸣识别作曲工具、Logo 设计工具建档，待补充实际项目入口。

## 引擎与编程

- [Unity Manual 学习指南](guides/unity.md) · [原始入口](https://docs.unity3d.com/Manual/)：Unity 官方手册：场景、组件、物理、渲染与构建。注意选择与项目一致的编辑器版本。 标签：Unity / C# / 官方文档。
- [Godot Docs 学习指南](guides/godot.md) · [原始入口](https://docs.godotengine.org/zh-cn/stable/)：Godot 中文官方文档，从第一个 2D 游戏到节点、信号与脚本。 标签：Godot / 2D / 开源。
- [Unreal Engine Documentation 学习指南](guides/unreal.md) · [原始入口](https://dev.epicgames.com/documentation/zh-cn/unreal-engine/)：虚幻引擎官方文档，查阅蓝图、关卡与渲染工作流。 标签：Unreal / 蓝图 / 3D。
- [Microsoft C# 文档 学习指南](guides/csharp.md) · [原始入口](https://learn.microsoft.com/zh-cn/dotnet/csharp/)：学习 C# 语法、类型与异步编程，作为 Unity 脚本开发的语言参考。 标签：C# / 基础 / 官方文档。

## 设计与架构

- [Game Programming Patterns 学习指南](guides/patterns.md) · [原始入口](https://gameprogrammingpatterns.com/)：在线阅读游戏编程模式，理解状态机、对象池、组件与事件队列。 标签：架构 / 设计模式 / 英文。
- [The Book of Shaders 学习指南](guides/shaders.md) · [原始入口](https://thebookofshaders.com/?lan=ch)：从图形与交互示例学习片元着色器，适合探索程序化视觉效果。 标签：Shader / 图形学 / 入门。

## 美术与素材

- [Kenney 学习指南](guides/kenney.md) · [原始入口](https://kenney.nl/assets)：查找原型制作所需的 2D、3D 与界面素材；下载时检查具体资源包的许可。 标签：原型 / 2D / 3D。
- [OpenGameArt 学习指南](guides/opengameart.md) · [原始入口](https://opengameart.org/)：社区游戏美术与音频素材。不同作品许可不同，使用前核对署名和分发要求。 标签：素材 / 社区 / 许可核对。
- [Blender Manual 学习指南](guides/blender.md) · [原始入口](https://docs.blender.org/manual/zh-hans/latest/)：Blender 中文官方手册，覆盖建模、动画、材质与导出。 标签：Blender / 建模 / 动画。

## 音频与音效

- [Freesound 学习指南](guides/freesound.md) · [原始入口](https://freesound.org/)：搜索环境声与音效。每条声音需要单独确认许可及商业使用条件。 标签：音效 / 环境声 / 许可核对。
- [Audacity Support 学习指南](guides/audacity.md) · [原始入口](https://support.audacityteam.org/)：学习录音、剪辑、降噪与导出，为游戏原型准备音频。 标签：音频编辑 / 工具 / 教程。

## 工具与发布

- [Git 官方中文书 学习指南](guides/git.md) · [原始入口](https://git-scm.com/book/zh/v2)：学习提交、分支与协作，让项目代码和开发记录可追踪。 标签：Git / 版本管理 / 中文。
- [itch.io 开发者文档 学习指南](guides/itchio.md) · [原始入口](https://itch.io/docs/creators/)：了解游戏页面、上传构建和发行流程，适合准备原型试玩页。 标签：发行 / 试玩 / 独立游戏。
- [Steamworks 文档 学习指南](guides/steamworks.md) · [原始入口](https://partner.steamgames.com/doc/home?l=schinese)：准备 Steam 商店页面与发行流程的官方参考，部分功能需要合作伙伴账号。 标签：Steam / 发行 / 官方文档。
