# Original slice models

`player.glb` is the runtime low-poly witch. `witch.blend` is its editable source.
All geometry and materials are original procedural work generated by
`../../../tools/build_models.py` in Blender 4.3.2; no downloaded models or images.

- Origin at feet, about 1.9 m tall, front is Godot -Z.
- Main tintable mesh/material names: `Cloak`, `CloakLining`, `Hood`.
- Gold seams, face, eyes and jewellery use separate materials.
- Runtime uses explicit GLB, not Blender auto-import.
- The slice animates transforms procedurally; this mesh is a static authored
  model and does not claim a production skeleton or cloth simulation.

Regenerate from repository project folder:

```sh
blender --background --python tools/build_models.py -- game/assets/models
```
