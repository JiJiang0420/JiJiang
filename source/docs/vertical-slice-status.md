# 垂直切片 v0.2 实现与验证状态

本文记录《魔女的盛宴 2.0》当前可交互切片的实际范围，不代表完整 GDD 已实现或所有平台已验收。试玩入口与操作见[项目 README](../README.md)。

## 本轮已实现的变化

- 8米范围圈、实际宽度的攻击带、目标圈、原因文字与飘字；验证与施法共用目标规则。
- 输入在有效范围/长度内截短；镜头拉近；敌人白闪、短时局部停顿、破甲碎片与新名称/轮廓。
- 初始六名饿客分两簇；侧面成组补充，前两次补充出现疯仆和背锅人，敌人上限12/18/24，首领阶段7。
- 短切、收线、推墙及各一张配套卡；第一店选择攻击分支，后两店优先配套/其他分支/通用。
- 试炼场Q可试用当前斗篷分支，右键优先取消绘制，其次执行主动收线/推墙。

完整设计见[攻击成长 V0.2](combat-growth-v0.2.md)。其中进一步的人群/单体路线与终局A/B选择仍未实现，不能把本轮三张配套当作完整成长树。

## 与完整 GDD 的主要差异

- 使用 Compatibility 渲染器，以便在当前环境完成图形验证；不是 GDD 中候选 Forward+ 的验证结果。
- 玩家模型为 Blender 生成的静态可编辑网格。动作主要通过节点变换、摆动和材质表现，没有已交付的正式动画骨架、精制动作集或布料模拟。
- 三斗篷共享同一基础模型，差异以颜色、纹样及程序反馈为主；完整独立轮廓设计仍需美术迭代。
- 当前只有三个样件变律和一个共织，未完成其余六个变律、其余共织、完整陈列室及剧情演出。
- 碰撞使用成对接触冷却与速度上限防止重复伤害，尚无完整 GDD 的统一连锁事件总线；数值与词条采用切片版参数，共织当前按残纱价格解锁，未加入完整历史里程碑门槛。
- 没有键位重绑、音量/画质设置菜单、文字缩放设置或手柄支持。
- 操作指南与试炼场代替完整分步教学。
- 不支持中途退出续局；仅保存已提交的永久进度。
- 不是完整发行版本，没有完成跨平台兼容、长时间平衡、目标配置性能或玩家可用性验收。

## 下一轮验收重点

1. 真实鼠标绘制与镜头/移动是否顺手，是否出现误触或难以选中的目标。
2. 正常镜头下是否能看懂连接、裁定、装甲破坏及碰撞结果。
3. 三分钟与八分钟流程是否都有合理压力和商店选择，三件斗篷是否有明显闲置。
4. Windows 实机导出包能否从新存档完成一局，再重启恢复永久进度。
5. 在确认的目标硬件上测量性能；不把云端软件渲染结果替代正式预算。

后续更新应分别说明修复、重新导出、机制测试、图形输入、平台验证和性能测量的结果，避免把一个环节通过写成全部验收通过。

本轮修复记录：持续牵引从瞬时冲量分离；生成预警期间冻结敌人；碰撞按实际相对速度及接近方向计算并保护死亡删除；手绘按输入事件即时采样；商店保留剩余冷却；强化窗口关闭与音频清理。自动检查均使用隔离临时存档。
