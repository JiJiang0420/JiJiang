# 《魔女的盛宴 2.0》三神斗篷系统 · 评审与补充 V1.1

状态：供用户评审，未批准开发。本文是策划修订建议，不代表功能已实现或数值已验证。

依据：[用户原稿 V1.0](three-cloaks-source-v1.0.md)及用户随后确认的两项方向。原稿保留原样，包括其中的参考链接；本轮未查看链接中的图片，不将其描述为已完成的视觉评审。

## 1. 已确认方向与本轮结论

用户已确认：

- PC，3D，可旋转视角，类幸存者战斗。
- 一个可操控身体，三件斗篷在战场切换，斗篷可局外成长。
- **手动绘制为主要攻击方式，三种魔法都能独立处理普通敌人。**
- **采用三位古神设定；“魔女”的身份另作解释。** 不默认将三位古神等同于最初提到的三位传说魔女。
- 先完成初步设计，再确定工序分工，用户检查验收后开始开发。

建议采用的定位：玩家通过手绘魔法改变敌人的结构、相互关系和运动边界，在持续增压的敌群中求生，并通过局内构筑与局外解锁改变自己的应对方式。

原稿最值得保留的是三种可相互作用的规则、切换后持续存在的魔法，以及斗篷作为长期成长资产的设计。当前优先补齐可操作的规则和完整战斗循环，再扩大正式资产制作。

除上述明确确认的方向外，下文均为待确认的补充或修订建议。数字只用于提出首轮测试条件，不是已平衡的正式参数。

## 3. 操作方案：保留绘制，降低无意义精度要求

建议采用斜俯视 3D 镜头，可绕玩家旋转；首轮固定俯仰角、限制缩放，控制遮挡。最终镜头高度与美术风格仍待选择。

| 输入 | 行为 |
| --- | --- |
| WASD | 相对当前镜头移动；施法和切换期间仍可移动 |
| 左键按住、拖动、松开 | 绘制并尝试释放当前权能 |
| 右键 | 取消尚未释放的绘制 |
| 1 / 2 / 3 | 直接选择绯月、星汐、圣棘；选择当前斗篷不触发切换 |
| 空格 | 闪避；具体距离、冷却及无敌规则另行测试 |
| 中键拖动 | 未绘制时旋转镜头 |

三种手势共用“预览—确认—释放”的反馈，但保留不同含义：绯月画短切线，星汐指定两端，圣棘画有方向的边界。避免复杂符号识别或要求贴着细小骨骼描线。

- 鼠标位置投射到统一战斗平面，已经采样的轨迹固定在世界中；镜头跟随移动不会拖动旧轨迹。
- 绘制期间暂停手动镜头旋转，不暂停世界；暂不加入自动慢动作。
- 星汐端点吸附到有效目标，显示选中轮廓；重叠目标提供明确选择优先级，不能在松手时随机换目标。
- 所有魔法显示长度、距离及有效性预览；超过范围截断或显示无效段，不把不可达位置伪装成有效结果。
- 首轮限定平坦战场，不支持跨楼层、空中目标和任意高度的切割。
- 三种魔法分别使用冷却，无效绘制不扣除资源、不启动冷却。暂不再增加共享法力条，避免三冷却之外出现第四个节奏约束。
- 绘制、切换、闪避的冲突由输入状态控制：取消绘制后必须重新按下左键，防止旧的松手事件误放新斗篷魔法。

绘制动作建议先以约 0.2–0.6 秒可以完成为操作目标，通过实际试玩确定是否需要更强吸附或更少敌方同步攻击。若负担过高，先调整这些因素；自动攻击不属于当前已确认方案。

## 4. 三件斗篷的基础规则

### 绯月：切开结构

短轨迹扫过敌人造成直接伤害；对标记的装甲部件施加破甲，对可打断攻击施加结构冲击。每个目标每次切割只结算一次，曲线反复描过同一目标不能刷命中。

装甲采用预制部件和少量破损阶段。装甲完整时牵引抗性较高；破损后暴露内部、降低对应抗性。首版不做任意网格切割，不要求每个普通小怪都有独立可拆肢体。

裂痕是有限时长的目标状态，同源刷新而不无限叠层。它可以提高下一次合格冲击的结构破坏收益；消费一次后移除。首版的合格冲击限定为达到条件的真实撞击与明确标记的结构冲击；普通牵引的逐帧位移、星汐收紧伤害、圣棘裁定伤害本身不消费裂痕。圣棘推开或偏转后导致的真实撞击可以消费。

独立用途：直接清理普通敌群、拆甲、处理明确可打断的蓄力。

### 星汐：建立联系

允许两类基础连接：敌人—敌人、敌人—地面锚点。地面锚点是法术生成的端点，不是另一件装备或另一种货币。

- 连接成功时出现一次可见的收紧脉冲，对敌方端点造成牵扯伤害；后续按质量与韧性施加有上限的牵引。
- 敌人—敌人连接使两端相互靠近；敌人—锚点连接将目标牵向锚点。首版不连接玩家，也不允许友方伤害。
- 收紧伤害不依赖实际发生碰撞，因此面对孤敌、位移受阻的敌人时仍有有效输出。
- 持续牵引主要改变位置，不按渲染帧反复制造伤害事件。撞击伤害另由合格的速度与碰撞事件结算。
- 一端死亡、连接超距或到时会结束连接；不同结束原因不自动等价于过载爆炸。

独立用途：脉冲击杀普通敌人、牵离危险位置、借地面锚点制造集中区。对孤敌也能完整施法。

### 圣棘：建立边界

绘制一条短边界，预览箭头标明裁定和偏转的方向。绘制反向时箭头反向；实际效果必须与预览一致。

- 边界落成覆盖敌人时，触发一次“立界裁定”，造成冲击伤害并向箭头一侧推开，提供主动进攻能力。
- 若落成时没有接触对象，则短暂保留，等待敌人、标记可偏转的冲锋或飞行物接触。
- 建议基础边界在首次有效接触批次结算后消失。批次定义为同一固定物理步收集到的有效接触；落成时也先收集全部覆盖目标，再统一结算和消失。同一批次的多个目标分别最多结算一次，即使同一目标同时满足落成与穿越条件也只受一次裁定；无效对象接触不消耗边界。
- 飞行物或冲锋只有带明确可偏转标记时才改变方向。普通不可偏转的近战攻击不会因碰到视觉边界而自动转向。
- 不破甲、不制造绯月裂痕；其独立价值来自立界命中、截断路线与改变攻击方向。

独立用途：在普通敌人身上立界造成伤害、布置一次性裁定陷阱、处理标记的冲锋或飞行物。敌人不主动进攻时，也能直接立界。

这一定义让“延界”具有明确含义：首次触发之后额外保留，而非在已经无限持续的边界上再加时长。

## 5. 切换、持续结构和冷却

**切换建议采用立即提交能力、短暂表现过渡。** 接受有效切换请求时，更新当前斗篷和 HUD，取消未释放的绘制。切换不重置、不刷新任何魔法冷却，不默认附送伤害、治疗或无敌。

原稿 0.18–0.25 秒作为首轮切换恢复窗口候选；窗口内可以移动、闪避，暂不开始新绘制。闪避打断切换动作后仍保留新斗篷，施法按闪避自身恢复规则执行。切换窗口内忽略额外切换请求，避免反复重启动画；若试玩证明不跟手，再评估单次输入缓存。

收势、甩动、遮盖、显现、恢复在约 11–15 帧中难以全部独立读清。优先保留甩动轮廓和材质过渡，余摆、纹样与粒子可延续到恢复操作之后。位移、身体动作和斗篷动画分层。

第一原型建议按类型固定两个持续结构槽：

| 类别 | 计数与结束规则 |
| --- | --- |
| 星汐连接 | 最多一条；两端与锚点合计一个结构；到时、端点死亡、超距或被同类新法术替换时结束 |
| 圣棘边界 | 最多一条；到时、基础触发耗尽或被新边界替换时结束 |
| 绯月裂痕 | 属于目标状态，不占结构槽；有限持续、刷新不叠层、按规则消费 |

这是对原稿“最多两个”的首轮收敛方案，会暂时限制双连接或双边界玩法；将来如放开共享两槽，应单独评审新的组合与替换体验。

新法术必须先通过有效性检查，再替换同类旧结构；预览标示将被替换的结构。替换、超距、死亡、自然结束分别记录原因，不能靠快速替换无限引爆过载。

每个已释放效果保留创建时的斗篷归属和配置，切换不会换色、换规则或刷新寿命。三件魔法冷却在离场时继续推进。首轮可测试连接约 4 秒、边界最多约 3 秒、裂痕约 6 秒；最终以玩家能否完成读得懂的组合为依据。

## 6. 组合与运动因果

基础联动从第一次完整战斗即可使用，不需要先解锁共织。单斗篷能处理普通敌人；组合提高效率、位置控制或面对特殊敌人的优势。

| 组合 | 可观察的基础结果 | 避免的误区 |
| --- | --- | --- |
| 绯月 → 星汐 | 装甲脱落降低抗牵引能力，同一目标更容易被拉离保护位置 | 不把“有裂痕”设为所有连接的前提 |
| 星汐 → 圣棘 | 将敌人拉近，再在聚集处立界裁定；或将冲锋者引至合适边界角度 | 不承诺连接后随意画线都必定撞中另一个目标 |
| 圣棘 → 绯月 | 偏转冲锋使敌人出现短暂失衡，提供更安全的切割时机 | 不把每一次切割强制锁在偏转之后 |

原稿的铁壳兽组合可以保留：破甲降低抗性 → 连接提供收束 → 合适角度的边界改向 → 碰撞造成冲击并消费裂痕。但边界方向、目标位置、冲锋速度必须真实影响结果，错误摆放也可能使敌人远离目标。

建议在固定物理步内统一处理：基础移动意图 → 有上限的牵引速度变化 → 边界接触与偏转 → 碰撞、冲击和状态结算。边界响应发生在接触位置并处理剩余运动，不能靠最后一帧瞬移制造命中。原型使用受控运动，不要求全场敌人都是可自由堆叠的刚体。

对位移速度、冲击伤害和同一对象对的碰撞触发次数设置上限。质量与韧性影响位移，基础施法伤害仍可生效。边界不作为永久不可穿越墙体，避免把敌群导航堵死。

防止无限连锁时，按“连锁来源 + 交互规则 + 目标”去重，而非让目标在整条连锁中只响应一次；后者会误杀合法的破甲、偏转和碰撞组合。派生效果继承来源，反射和碰撞不能不断重置为新来源；首轮可限制最多四层派生，再记录哪些有效组合被截断。

反射物改为玩家伤害归属，同一投射物首版最多反射一次，反射后不伤害玩家。击杀、货币和成长奖励只结算一次。

### Boss 的规则边界

Boss 使用韧性、阶段窗口和专门交互部位。星汐可贡献牵扯伤害与较小的位移或韧性效果；圣棘有主动裁定及标记攻击的偏转机会。不得把两件斗篷整体标为 Boss 免疫。

首轮可处理有明确预警的冲锋、飞行物和冲击波。任意近战横扫反向、任意身体切割和任意环境破坏延后评审；需要专门动画与关卡设计时再逐项加入。

## 7. 局外成长：核心从开局可玩，成长增加选择

三件斗篷、基础绘制、切换、效果保留及基础联动在教学结束前全部开放。教学中的“复原”用于介绍规则，后续复原体现外观与神权理解，不能靠长期付费解锁基本操作。

建议配置规则：每件斗篷装备一个变律，全角色装备一个共织；基地免费调整。解锁拥有权与本局选用配置分开，死亡不丢失永久解锁。共织中后期开放可保留，但只是改变联动收益。

原稿中的九个变律可作为候选基础，补充以下取舍方向；这些取舍不预设最终数值。其中“双向牵引”已与基础连接重复，建议改为强调施法时机的“回潮”。

| 斗篷与变律 | 保留的行为变化 | 建议的代价或约束 |
| --- | --- | --- |
| 绯月·裂纹延伸 | 裂痕向相邻的有效结构节点扩展 | 即时破甲较弱；传播对象和跳数有限 |
| 绯月·断骨 | 下一次合格冲击更容易破坏结构 | 直接切割收益降低；需要后续冲击兑现 |
| 绯月·回斩 | 同轨迹延迟回切 | 主斩较弱；敌人可能离开原路径 |
| 星汐·回潮（替代双向牵引） | 持续牵引改为建立时与到期前的两次定时收束，单敌模式围绕锚点收束 | 两次之间失去持续拉力；第二次收束不额外复制收紧伤害，需要配合敌人运动时机 |
| 星汐·单向导流 | 第一端提供方向，第二端承受位移 | 来源端不再被拉动；地面端只能作为来源，预览显示有效方向 |
| 星汐·过载连接 | 自然结束时释放有上限的积累 | 持续牵引较弱；替换、死亡、超距、手动取消不触发释放 |
| 圣棘·折界 | 最多一个转折点 | 总长度不变，两段共享一次触发批次，同一目标不双倍受伤 |
| 圣棘·回返 | 可反射飞行物转为反向返回 | 对单位的偏转能力降低；无飞行物时仍可立界伤害普通敌人 |
| 圣棘·延界 | 首次触发后短暂保留，允许一次额外接触批次 | 单次裁定较弱；同一目标每条边界只响应一次，包括伤害与偏转；额外批次或固定截止时间到达即消失，后续触发不续时 |

原稿三个共织建议用可观察触发定义，避免“更容易”无法验收：

- 绯月 → 星汐：裂痕目标被连接后的首次收紧获得额外牵引收益；基础破甲降低抗性的效果无需此共织。
- 星汐 → 圣棘：边界实际命中已连接目标时，提高本次偏转对韧性的作用；仅按切换键不触发。
- 圣棘 → 绯月：成功偏转的目标短暂显现可切割破绽，下一次合格切割消费该机会。

首轮不要求三种共织都做完，可选一个验证装配与行为改变。仅原稿三件各三种变律、三选一共织就有 81 种组合，尚不含基础配置与局内强化；应逐步扩大组合测试。

## 8. 局内循环与两种货币

建议的一局流程：基地配置 → 进入战场 → 击败敌群取得宴屑 → 波段结束时购买本局强化 → 应对精英与首领 → 结算残纱 → 返回基地。

| 资源 | 获取与使用建议 | 结束规则 |
| --- | --- | --- |
| 宴屑 | 敌人战斗产出及阶段奖励；波段间购买本局强化 | 胜利或失败均清空；不能兑换为残纱 |
| 残纱 | 完成阶段与目标后结算，胜利额外奖励；用于永久解锁 | 已结算部分失败保留；不按重复连锁命中次数刷产出 |

首轮商店在安全间歇暂停战斗和局内计时，提供三个相关选项。购买的强化持续到本局结束；标明叠加上限；排除当前配置下没有合法触发方式的词条。初版不加入重抽费用和经验球升级体系。

局内强化在当局深化所选玩法，不给局外已经有的变律换名字再卖一次。例如延长链接距离可以改变站位选择，但必须有最大距离和冲击收益上限；裂痕传播需要限定次数，不能因宴屑购买绕开连锁限制。

完整循环样件可先测试约八分钟：前三个两分钟波段逐步引入普通敌群、冲锋与装甲单位，段间进入商店；最后约两分钟为首领窗口。首领击败则胜利，生命归零则失败，超时规则在样件中明确展示。此时长与商店频率仅为候选，不代表正式关卡已定。

战斗密度通过敌人数、出招频率、组合和场地压力共同增长。大量普通敌人提供清理反馈，少量精英提供值得组合的规则目标；不让所有杂兵都要求三次精确手绘。敌方远程攻击与冲锋采用出招额度，避免所有敌人同一时刻爆发。

## 9. 世界观与三件遗物的视觉方向

三位古神的断裂、流转、界定法则沿用原稿。“承宴者”为暂定玩家称谓。需要补全“魔女”和“盛宴”与玩家目标的关系，但不让这些名称反过来阻塞基础战斗规则。

可供讨论的一句衔接：**魔女是能把神性编织成魔法的凡人；承宴者是获准披挂遗物、进入盛宴的人。** 这是新增提案，不是已经确认的世界观。盛宴的举办者、敌人来源、玩家为何参与、胜利改变什么，留待剧情设计确认。

以下是原创视觉任务的文字方向，尚非完整美术定稿：

| 斗篷 | 轮廓与材质方向 | 运动与法术识别 | 成长反馈 |
| --- | --- | --- | --- |
| 绯月 | 不对称锐角下摆、断缝和分段纹样；暗布配猩红内衬 | 短促甩动、断续切线、明确装甲脱落 | 破损边缘逐步形成可控的神性裂纹 |
| 星汐 | 连续弧线与双尾、结点和流线纹样；深色布面配紫银细线 | 有延迟的柔性拖尾、端点结环、可见流向 | 布面流路逐步连通，结点变得清晰 |
| 圣棘 | 对称垂直轮廓、几何镶边与棘纹；骨白与旧金 | 稳定张开、直线和转角、清晰裁定方向箭头 | 暗纹依次点亮，边缘形成完整神性边框 |

不能只靠红、紫、金区分斗篷；轮廓、符号、线型与声音都应提供信息。实际战斗镜头下，斗篷不能遮挡脚下危险区；敌方致命预警优先于己方装饰粒子显示。生效范围要与视觉宽度一致。

共享一个玩家身体、基础骨架和切换动作，再通过斗篷轮廓、材质与次级动作区分三神。Blender 制作可控骨骼摆动，Godot 补充材质和次级波动；实时布料模拟在主运动可读、性能可接受之后再评估。

记忆外观绑定明确的复原或挑战里程碑，进度可查看。保留已获得的外观展示选择，不加入随机耐久或维修费用。完整陈列室属于后续表现；早期简单预览也必须能看出遗物本体的变化。

## 10. 制作范围与推进建议

当前仓库未发现 `project.godot`、`.gd`、`.tscn`、`.blend` 或 `.kra`。原稿所述已有 V0.1 原型不能视为当前实现基础；如另有工程，后续提供后再评估复用。

设计和分工验收之后，建议按两个样件推进；本文件只定义候选范围，尚未启动这些工作。

| 阶段 | 建议范围 | 主要回答的问题 |
| --- | --- | --- |
| A：战斗与视觉样件 | 一个平坦测试场、一个身体与共享骨架、三种斗篷轮廓/纹样、一个切换动作、三种基础权能、普通追逐者/窜行者/铁壳兽、可控飞行物测试器、三组双斗篷互动 | 操作能否跟得上？每件能否独立战斗？因果是否清楚？正常镜头能否认出斗篷？ |
| B：完整短局样件 | 在 A 基础上加一个首领、两种货币、段间商店、每斗篷一个可装卸变律、一个共织、简单基地预览与永久进度保存 | 一局是否有节奏与构筑变化？成长能否改变玩法且正确保存？ |

先完成三斗篷同屏对照设计和一套可替换的视觉样件，保证识别度；完整高精角色、三套独立正式切换动画、复杂布料、全套九变律、完整陈列室、可破坏环境和多个关卡后续再排期。

架构上建议保留原稿的单一玩家主体、斗篷管理、三权能模块和统一交互入口，并补齐效果生命周期、目标交互标签、成长配置与本局状态的边界。已释放效果由独立实例管理，不能挂在切走即销毁的斗篷节点下。具体脚本划分在分工阶段确定。

资产约定届时统一：Krita 源文件与 PNG 导出、Blender 源文件与显式 GLB 导出分别保留；模型单位、骨架、动作片段、透明通道、特效尺寸与 Godot 导入设置一致。先用一个样件打通导出与导入再批量制作。

## 11. 供验收使用的检查清单

以下均为未来样件的验收方案，当前没有可运行工程，也未执行这些测试。

| 检查 | 设置与动作 | 预期可观察结果 |
| --- | --- | --- |
| 单斗篷可用 | 分别用三件斗篷面对普通孤敌及小群敌人 | 每件都有合法、可重复的基础攻击；无需切到绯月补最后一击 |
| 手绘与镜头 | 移动中绘制，尝试旋转镜头并取消 | 轨迹不漂移、镜头旋转不抢手势；取消不扣冷却或误放另一种魔法 |
| 切换一致性 | 移动、绘制、切换和闪避交错操作 | 玩家保持一个身体；当前能力与 HUD、最终外观一致；切换不增加无敌、不重置法术冷却 |
| 效果延续 | 建立连接和边界后换斗篷 | 原效果按原配置和原寿命继续存在 |
| 结构替换 | 有旧连接时尝试无效新连接，再释放有效新连接 | 无效操作保留旧结构；有效操作只替换同类；过载不因替换引爆 |
| 因果组合 | 重复三组双斗篷场景并改变站位、方向 | 结果可解释；错误角度不会自动修正成完美连招 |
| 防循环 | 连续穿越延界、反射物再接触、敌人重复碰撞 | 触发和伤害有界；同一击杀只结算一次奖励 |
| 基础玩法开放 | 新存档完成短教学 | 能使用三件基础权能及基础互动，不依赖付费复原或共织 |
| 变律有区别 | 同一场景装卸一个变律 | 轨迹、牵引或边界行为发生可辨识变化，并能观察代价 |
| 经济与保存 | 完成或失败一局、返回基地、重启程序 | 宴屑与局内强化清空；已结算残纱、永久解锁和装备配置保留 |
| 视觉辨识 | 去掉斗篷文字提示，在正常战斗镜头观察 | 根据轮廓、图形和运动判断斗篷；关键敌方预警仍清楚 |
| 性能 | 固定硬件、分辨率、敌人数、两结构和特效强度 | 记录帧时间及峰值；以确定的目标预算验收，未指定硬件前不承诺百怪稳定 60 帧 |

首轮试玩还应记录：无效绘制比例、各斗篷使用和击杀分布、成功组合次数、玩家能否复述死亡原因与组合因果。数据用于发现闲置斗篷和操作负担，不要求三件使用率机械地各占三分之一。

## 12. 本轮仍需确认的设计选择

已确认的手动绘制、PC 3D 与三古神方向不再重复提问。下一次评审优先讨论：

1. 是否接受星汐“敌人—地面锚点 + 收紧脉冲”和圣棘“立界裁定”的独立进攻补充。
2. 是否接受首轮一条连接、一条边界，以及基础边界首次接触即结算消失的范围。
3. 是否接受核心能力开局完整、每件一个变律加全局一个共织的成长边界。

镜头俯仰、美术风格、目标硬件、正式单局长度和世界观细节可继续迭代。上述设计验收后，再形成按工序划分的任务、交付物、依赖与验收标准；用户批准后进入制作。
