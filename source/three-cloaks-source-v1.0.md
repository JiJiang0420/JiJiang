# 三、三件斗篷如何组合

我认为这是整个系统真正的核心。

我们不能让三种魔法互相独立，否则玩家只是在三个技能之间轮流使用。

它们应该拥有明确的因果关系。

## 三神权能的交互关系

绯月：改变结构

让目标变得破损、脆弱、失去完整性。

结构变化产生新的连接条件

星汐：改变关系

将目标与其他目标、力量或运动状态联系起来。

关系变化产生新的运动结果

圣棘：改变规则

利用空间边界改变运动、碰撞和攻击结果。

改变后的战场产生新的破坏机会

重新回到绯月

利用新的机会继续改变目标结构

这不是强制连招，而是一套能够循环利用的战斗规则。

例如：

- 绯月切开铁壳兽。
- 星汐连接它与窜行者。
- 圣棘偏转窜行者的冲锋。
- 窜行者撞击铁壳兽。
- 铁壳兽的装甲进一步破损。

玩家完成了一次跨斗篷的战场组合。

这才是值得玩家反复探索的内容。

## 一个重要限制

为了避免战场变成特效和连锁反应的混乱集合，我建议：

- 同一时间只允许玩家主动绘制一种魔法。
- 已经建立的魔法结构可以在切换后继续存在。
- 第一版最多保留两个持续性魔法结构。
- 同一目标在一次连锁事件中不能无限重复触发。

这样既保留组合空间，又不会让玩家失去对战场的理解。

# 五、斗篷的局外成长系统

这是我最希望重点建设的部分。

我建议把三件斗篷设计成游戏的主要长期成长资产。

玩家不是不断收集新的角色，而是在不断修复、解封和强化三件神授斗篷。

## 5.1 成长结构

## 三层成长架构

第一层

斗篷复原

恢复斗篷的基础神权，解锁基础魔法和核心交互。

第二层

斗篷变律

解锁不同的魔法规则，玩家可以在局外选择自己喜欢的战斗方式。

第三层

三神共织

解锁跨斗篷联动，让切换斗篷本身也成为战斗策略的一部分。

我建议三件斗篷的基础能力从游戏早期就能使用，不要把核心切换玩法锁在长期养成之后。

成长应该扩大玩法，而不是补齐游戏本来就应该提供的基础操作。

# 六、三神共织：真正让斗篷成长起来

这一层我建议放在中后期。

它不应该是简单的三种魔法同时增强，而是专门强化斗篷之间的转换。

例如：

| 切换关系    | 共织效果              |
| ------- | ----------------- |
| 绯月 → 星汐 | 裂痕目标更容易受到牵引       |
| 星汐 → 圣棘 | 已连接目标的运动更容易受到边界影响 |
| 圣棘 → 绯月 | 被偏转的目标留下短暂结构破绽    |

我建议采用一个非常克制的设计：

玩家可以解锁全部共织规则，但局外只能选择其中一种作为本局的核心共鸣。

这样可以形成不同的构筑路线，又不会出现所有效果同时叠加导致的复杂度失控。

# 七、局内构筑与局外成长必须分开

这是经济设计中非常重要的边界。

| 对比   | 局外成长       | 局内构筑      |
| ---- | ---------- | --------- |
| 持续时间 | 永久         | 仅本局       |
| 主要目标 | 解锁规则       | 形成构筑      |
| 成长内容 | 斗篷复原、变律、共织 | 魔法强化、特殊交互 |
| 资源   | 残纱         | 宴屑        |
| 重置   | 可在基地调整配置   | 每局结束清空    |

我建议不要继续增加货币。

只保留两种：

- 残纱：长期积累，用于斗篷成长。
- 宴屑：战斗获得，用于本局商店。

局内强化的例子：

- 绯月切割后，裂痕可以短暂传递给相邻怪物。
- 星汐连接的目标越远，收束时产生的力量越大。
- 圣棘成功偏转三次攻击后，边界获得一次强化。

这些才是能改变玩家实际操作的 Roguelite 强化。

- 三件斗篷拥有独立魔法规则。
- 三种魔法具有不同视觉反馈。
- 已经建立的魔法效果不会因为切换而消失。
- 不同斗篷之间可以产生规则联动。
- 成长效果能够改变魔法的实际行为。
- 局内成长与局外成长相互独立。

# 十、我还想增加一个值得长期发展的设计

斗篷应该拥有自己的记忆。

这不是让斗篷变成普通装备，而是让它们随着玩家的使用逐渐发生变化。

例如：

- 绯月经历多次战斗后，斗篷的边缘逐渐出现撕裂状的猩红纹路。
- 星汐随着力量复原，布料上逐渐出现流动的紫色纹理。
- 圣棘随着神权解封，原本暗淡的金白色符文逐渐点亮。

这些变化可以与局外成长等级对应。

但我不建议做随机耐久损耗或需要玩家维修的负担。它应该是纯粹的成长反馈。

这样玩家会对三件斗篷产生长期的情感联系。

# 十一、下一阶段我建议这样推进

我们现在已经有了一个比较完整的设计方向，但还需要解决一个影响游戏商业辨识度的问题：

玩家在战斗中切换斗篷，究竟是为了切换攻击方式，还是为了改变整个战场的规则？

我的选择是后者。

如果只是攻击方式，三件斗篷很容易变成三套普通技能。

如果它们能够改变结构、力量关系和空间规则，那么玩家每一次切换都可能改变战场局势。

我建议将这句话作为《魔女的盛宴2.0》的核心设计原则：

> 你只有一个身体，却能披挂三种神权。你不是在攻击敌人，而是在改写战场发生的方式。

接下来，我建议直接推进一个具体的设计任务：

制作三件斗篷的完整视觉设计与战斗切换演示原型。

先把同一个角色穿戴三件斗篷的外观、布料动态、切换动作和三套魔法反馈做出来。只有当玩家一眼就能分辨三件斗篷，并且切换时有明显的视觉与操作满足感，我们才值得继续扩大整个系统。
