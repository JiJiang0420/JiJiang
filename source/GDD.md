## 1. 产品定位与已确认方向

### 1.1 用户已确认

- 项目为《魔女的盛宴 2.0》，跳过 1.0 的旧设计。
- PC、3D、可旋转视角、类幸存者战斗。
- 玩家始终操控一个身体，战场中切换三件斗篷，以不同权能配合战斗。
- 手动绘制是主要攻击方式，三种魔法都能独立处理普通敌人。
- 三件斗篷可以局外成长。
- 世界观采用三位古神；“魔女”另作解释。
- 先完成设计，再制定各工序分工，由用户检查验收后开始开发。

### 1.2 本次提交的产品方案

### 1.3 设计原则

1. 单斗篷可行动，组合带来额外机会，不把三段固定连招作为杂兵门槛。
2. 变化应能看见：装甲脱落、连线收紧、方向偏转都有对应反馈。
3. 同一法则在不同场景中保持一致，特殊例外须有明确标识。
4. 操作围绕短手势和站位，不要求高精度绘画。
5. 成长增加规则选择；基础操作和基础联动从开局完整提供。
6. 优先保证玩家位置、敌方预警与施法方向可读，再增加装饰表现。

## 2. 世界观与体验目标

以下为衔接名称与战斗循环的剧情提案，待本次验收。

世界由断裂、流转、界定三种古老法则维系。古神退隐后，残留神性周期性汇聚成“盛宴”，吞噬现实边缘并催生宴场中的敌群。三件神授斗篷保存了古神的权能与不完整意志。

“魔女”是能够将神性编织为魔法的凡人。“承宴者”是获准进入宴场、披挂遗物的身份。玩家是一名承宴者魔女，以一个身体承载三件斗篷，进入宴场击败老厨子，回收残纱，修复故乡正在衰败的保护结界。

三位古神不需要三个独立可操控角色。她们通过斗篷纹样、短句和记忆片段表达意志：为什么帮助玩家、需要玩家付出什么，作为后续叙事空间。

| 神权 | 斗篷 | 作用对象 | 玩家感受 |
| --- | --- | --- | --- |
| 断裂 | 绯月 | 身体、装甲、可破坏结构 | 我拆开了敌人的防护 |
| 流转 | 星汐 | 两个目标之间的联系和运动 | 我让力量沿新的关系流动 |
| 界定 | 圣棘 | 位置、路线、可偏转攻击 | 我决定这条边界如何影响战场 |

完整短局只需开场短文、基地目标、首领介绍和结算变化。完整角色身世、古神真名、分支剧情和结局不作为第一轮制作前置。

## 3. 核心循环与一局流程

### 3.1 三层循环

- 秒级：观察攻击预警 → 移动与绘制 → 释放神权 → 利用结构或位置变化 → 再施法或切换。
- 局内：清理敌群 → 获得宴屑 → 波段间购买强化 → 应对更复杂的敌群 → 挑战老厨子。
- 局外：结算残纱 → 解锁并装配变律/共织 → 查看斗篷记忆变化 → 重新进入盛宴。

### 3.2 完整短局的状态顺序

标题 → 基地配置 → 战斗第一段 → 商店 → 战斗第二段 → 商店 → 战斗第三段 → 商店 → 首领 → 胜败结算 → 基地。

| 战斗计时 | 内容与目的 | 结束处理 |
| --- | --- | --- |
| 0:00–2:00 | 饿客为主，少量疯仆；熟悉独立施法与移动 | 发放第一段奖励，进入商店 |
| 2:00–4:00 | 引入背锅人；引导破甲、牵引与路线利用 | 发放第二段奖励，进入商店 |
| 4:00–6:00 | 三类敌人组合，增加空间压力 | 发放第三段奖励，进入商店 |
| 6:00–8:00 | 老厨子；保留有限普通敌人，避免多种高威胁同时启动 | 击败首领则胜利；达到 8:00 仍未击败则失败 |

商店开启时停止生成敌人，剩余敌人和飞行物退场，不产生击杀奖励；自动收取已掉落但未拾取的宴屑。持续法术以“阶段清理”原因结束，不触发过载。商店暂停战斗计时，离开商店再开始下一段。生命和剩余施法/闪避冷却保留；商店时间不推进它们，离店不免费刷新。

玩家生命归零随时结束战斗。首领与玩家在同一物理步死亡时，本稿选择胜利；首领在截止的同一物理步被击败同样判胜。结算优先顺序详见第 12 节。

八分钟与硬截止属于短局样件方案。若测试显示持续手绘疲劳或三斗篷对首领的有效输出不足，先调整战斗节奏和规则，不以压缩时间代替修正问题。

### 3.3 一段代表性战斗

玩家先用绯月在饿客群中划出切线，对背锅人同时造成破甲与裂痕。切换星汐，将失去装甲的背锅人和正在蓄力的疯仆连接。通过移动与连线收束形成合适的位置，再用圣棘画出箭头朝向背锅人的边界。冲锋接触边界后改向，实际碰撞消费裂痕并产生额外结构冲击。

这是一种有条件成立的示例。若位置、角度或时机不合适，偏转可能把疯仆送离目标；基础法术伤害仍然成立，玩家可继续调整。游戏不自动把所有三斗篷操作修正为成功连招。

## 4. 操作、镜头与玩家规则

### 4.1 默认输入

| 输入 | 行为 |
| --- | --- |
| WASD | 镜头相对移动 |
| 左键按住、拖动、松开 | 开始绘制、预览并尝试释放当前权能 |
| 右键 | 取消未释放绘制 |
| 1 / 2 / 3 | 选择绯月 / 星汐 / 圣棘 |
| 空格 | 按移动方向闪避；无移动输入时沿角色朝向闪避 |
| 中键拖动 | 旋转镜头；可重绑为其他输入 |
| Home | 镜头回到默认朝向；绘制时无效 |
| Esc | 取消当前绘制并打开暂停菜单 |

首版不要求手柄支持。镜头为斜俯视透视镜头，候选俯角 55°，允许水平旋转；固定战斗缩放。角色应始终处于可观察区域，遮挡角色的场景装饰淡出。镜头震动可关闭。

绘制期间冻结镜头旋转，继续允许移动与镜头平移跟随。轨迹采样到地面世界坐标，已采样点不随镜头拖动。首个场地采用单一平面，不支持跨楼层或空中绘制。

### 4.2 玩家起始参数（待实测）

| 参数 | 原型起始值 |
| --- | --- |
| 最大生命 | 100 |
| 移动速度 | 5.2 米/秒；斜向速度归一化 |
| 闪避 | 位移 2.6 米、动作 0.22 秒、冷却 1.4 秒；碰到场景实体即截断 |
| 闪避保护 | 动作第 0.04–0.16 秒免受伤害，可穿过普通敌人；不能穿过场景边界 |
| 受击保护 | 非致死受击后 0.25 秒，避免同帧多敌瞬间叠伤；不叠加延长 |
| 施法与切换移动 | 保持基础移动速度 |
| 共享法力 | 首版不设置；三权能独立冷却 |

闪避的保护与斗篷切换分开。切换没有无敌、治疗或免费伤害，不能重置闪避冷却。身体接触不逐帧造成伤害，敌方伤害来自明确攻击事件。

### 4.3 输入状态与打断

普通状态可移动、绘制、切换和闪避。绘制时切换或闪避会取消未释放法术，不启动其冷却。切换被接受时立即提交新斗篷、更新图标；用约 0.22 秒完成施法恢复，期间仍可移动和闪避。

切换过程中忽略追加切换请求；闪避过程中不开始绘制或新的切换。闪避打断切换表现时保留已提交斗篷，随后按闪避恢复规则进入可施法状态。选择当前斗篷不播放动作、不触发共织。

任何取消、失焦、暂停或 UI 切换之后，必须重新按下绘制键才开始新手势；残留的松手事件不能释放另一件斗篷的法术。死亡与结算禁止新的战斗输入。

## 5. 三神斗篷与手绘施法

### 5.1 统一施法约定

- 每次绘制显示有效范围、作用路径或端点、释放方向，以及将替换的持续结构。
- 三魔法有效释放时才启动各自冷却，冷却在切走后继续推进；未就绪时显示剩余时间，不播放成功释放反馈。
- 绘制采用短手势，目标是在约 0.2–0.6 秒内完成常规施法；这不是强制最短按住时间。
- 超过 2.4 秒仍未释放则取消，并给出轻提示；世界始终继续运行。
- 最大施法距离以释放时玩家位置检查；有效路径与端点都应处于半径 8 米内。预览即时标示无效区域，验证失败则整次取消，不删除旧结构。
- 目标吸附提供轮廓与明确端点。首端在按下时锁定目标身份；末端选择以释放前的预览为准。重叠目标按鼠标距投影中心排序，再以稳定对象标识打破相同距离，不能随机选择。
- 不要求识别复杂符号。绯月接受短曲线，星汐选择端点，圣棘基础形态是有方向的直线。

- v0.2 常驻显示 8 米施法圈；红色攻击带、金色边界带按真实判定宽度显示。鼠标拖绘达到范围或长度上限时截短预览，松手按可见路径释放；起笔仍需在圆圈内。程序接口及移动端点仍执行同一合法性检查。
- 飘字显示实际生命伤害；破甲显示碎片和文字，受击只令该敌人短暂停顿，玩家移动不中断。无效释放说明具体原因，挥空与命中分开反馈。

### 5.2 基础数值表（待实测）

| 参数 | 绯月 | 星汐 | 圣棘 |
| --- | --- | --- | --- |
| 生命伤害 | 每目标 24 | 每个敌方端点 20，仅建立时 | 每个有效目标 20 |
| 独立冷却 | 1.2 秒 | 1.6 秒 | 1.8 秒 |
| 形状限制 | 路径总长 8 米，宽 0.7 米，至少 0.35 米 | 两端距离最多 8 米，至少一个敌人，不允许同一敌人两端自连 | 线长 0.5–6 米，宽 0.6 米 |
| 存续 | 瞬时切割；裂痕 6 秒 | 最长 4 秒；端点距离超过 10 米断开 | 最长 3 秒或首次有效接触批次完成 |
| 特殊作用 | 装甲结构伤害 20；施加裂痕 | 有上限的持续牵引；基础收束速度贡献最多 3 米/秒 | 普通目标在 0.15 秒内推开最多 1.5 米；指定攻击改向 |

普通饿客生命为 36，三件基础权能均能用两次有效施法独立击杀。命中数量、控制能力与组合收益不同，不要求三件斗篷所有情况下效率相同。

### 5.3 绯月：断裂之权

释放时，对轨迹覆盖的有效敌人结算一次生命伤害与结构伤害。路径反复经过同一目标不重复命中。装甲采用预制部件和破损阶段；首版不做实时任意网格切割。

命中施加一层裂痕，持续 6 秒，再次施加只刷新。裂痕让下一次合格撞击的结构伤害增加 50%，随后消费；它不额外放大该撞击的生命伤害。

首版合格撞击为达到阈值的实际冲锋/强制位移碰撞。普通牵引的逐帧变化、星汐建立伤害、圣棘裁定伤害和下一次普通切割都不直接消费裂痕。圣棘改向后导致的真实碰撞可以消费。结构伤害也能打断明确标记的疯仆蓄力，普通攻击不因此自动被打断。

### 5.4 星汐：流转之权

支持敌人—敌人和敌人—地面锚点。基础形态允许任一端先选地面，但两端全是地面无效；单向导流变律有额外方向要求。

连接建立时，两端敌人分别受到一次可见的收紧伤害。之后敌人—敌人相互靠近，敌人—锚点向锚点靠近；运动受装甲、质量和韧性影响。基础伤害不依赖实际位移或撞击，因此单独的敌人也可被击杀。

收紧伤害先结算；若造成端点死亡，该条连接立即结束，不反复寻找替代目标。连接不连接玩家，不产生友方伤害。敌人被阻挡时停止对应位移，不穿透墙体。

### 5.5 圣棘：界定之权

从 A 画向 B，箭头指向俯视下该有向线的左侧法线。普通敌人向箭头方向推开；带可偏转标记的飞行物或冲锋将运动方向改为箭头方向，速度保留但受上限限制。反向绘线只翻转箭头。

基础规则是方向重定向，不是镜面反射或沿边界滑行。“回返”变律才将飞行物改为入射方向的反向。玩家看到的预览箭头必须使用实际结算方向。

边界落成时收集覆盖的敌人，立刻触发裁定伤害与推开；没有接触则保留，等待穿越。首次有效接触批次是同一个固定物理步内收集的全部有效接触，收集后统一结算，再销毁边界。无效对象接触不消耗它。

同一目标在同一边界中最多响应一次，包括伤害与偏转。落成与穿越同时满足也不重复结算。圣棘不直接伤害装甲结构、不制造裂痕；它导致的真实撞击按独立碰撞规则处理。

首领或疯仆处于明确可偏转的冲锋时，重定向不再乘普通推力抗性，以免预览失真；非冲锋状态的普通推开按抗性衰减。不可偏转的范围震击不会被边界取消。

| 圣棘·推墙 | 布置后最多等待3秒；右键后以6米/秒向箭头推进2.5米，首批24伤害；冷却2.2秒 | 待发阶段不伤害、不偏转，需要额外操作 |

右键先取消正在绘制的手势，不同时触发分支。收线早按只拒绝，不排队；自然结束、替换或端点死亡不补伤。推墙命中一批或走完整段行程即结束。新分支在本局覆盖该斗篷原先装配的局外变律，二者不叠加，永久装配不被修改。

试炼场按 Q 仅切换当前斗篷的基础/分支模式，不写入存档、不刷新冷却；正式战斗通过商店选分支。更完整的分叉、三阶段成长与验收条件见[攻击成长 V0.2](docs/combat-growth-v0.2.md)，其中标为后续的分支并未全部实现。

## 6. 交互、持续效果与连锁规则

### 6.1 两个结构槽

首版最多一条星汐连接、一条圣棘边界。连接的两端及锚点合算一个结构；裂痕是附着于敌人的状态，不占槽位。新的有效同类法术替换旧结构；无效释放保留旧结构。HUD 显示结构类型、剩余时间与替换提示。

每个效果保存创建时的斗篷、配置、来源与寿命，切换不改变它们。结束原因至少区分：自然到时、端点死亡、超距、新法术替换、阶段清理。只有明文允许的结束原因才触发终结效果。

### 6.2 运动与撞击

固定物理步按“基础运动意图 → 有上限的牵引 → 边界接触与改向 → 碰撞和伤害 → 状态与死亡处理”结算。接触在实际路径位置求解，不通过最后一帧瞬移伪造命中。

首版实际撞击需要一方处于冲锋或强制位移，且相对接近速度达到 4 米/秒。基础撞击对每个参与的敌方单位造成生命伤害 10、结构伤害 20；同一对象对在同一连锁中只结算一次，并有 0.5 秒重复碰撞保护。相向接近不足阈值的普通拥挤不伤害敌人。

先用是否存在裂痕决定本次撞击的结构伤害，再消费裂痕。目标装甲完整时，本次生命伤害按命中前减伤计算；结构伤害独立结算，破甲后的下一次命中使用新状态。

边界不能形成永久不可穿越的导航墙。强制运动总速度上限候选为 12 米/秒，范围和撞击伤害不随加速无限增长。

### 6.3 三组基础联动

| 联动 | 直接结果 | 初始是否开放 |
| --- | --- | --- |
| 绯月 → 星汐 | 破甲降低牵引抗性，便于拉离或聚集 | 是 |
| 星汐 → 圣棘 | 聚集后多目标立界，或布置可用的冲锋改向机会 | 是 |
| 圣棘 → 绯月 | 偏转后的恢复窗口便于切割；真实碰撞可消费裂痕 | 是 |

共织只改变联动收益，不解锁上述基础关系。

### 6.4 防循环与奖励归属

派生效果继承连锁来源；按“来源 + 规则 + 目标”去重，不能简单让一个目标整条连锁只触发一次。候选上限为四层派生，超出时停止派生并留调试记录。回斩等明确的第二段攻击使用独立规则阶段，但不重置连锁来源。

同一飞行物首版最多偏转一次。被玩家偏转后归属玩家，不再伤害玩家；再次碰到边界不触发新的偏转。碰撞继承最后一次实际改变该攻击者运动的有效法术来源；没有法术干预则沿用敌方攻击来源。裂痕只修改既有碰撞，不另建来源。敌人死亡、宴屑和阶段奖励分别具有唯一结算标识，只发放一次。

## 7. 敌人、首领与关卡节奏

### 7.1 三类基础敌人（起始参数）

| 敌人 | 数值和行为 | 主要学习点 |
| --- | --- | --- |
| 饿客 | HP 36，速度 3.15 米/秒；近身攻击伤害 8，前摇 0.65 秒，间隔 1.4 秒 | 观察群体路线，用三种权能分别完成清理 |
| 疯仆 | HP 60；冲锋伤害 18，速度 8 米/秒；前摇 1 秒，末 0.4 秒锁定方向；恢复 1.2 秒 | 切割打断标记蓄力、提前牵引改变位置、边界改向 |
| 背锅人 | HP 100，速度 1.8 米/秒；近身伤害 16，前摇 1 秒；装甲结构值 40，完整时生命减伤 35%、牵引和普通推开效果为 25% | 两次基础切割拆甲；未破甲也可被其他两件缓慢击杀；破甲后位移效果恢复为 100% |

被偏转的疯仆完成当前冲锋后进入原定恢复期，不重新蓄力；持续碰撞不无限重置恢复。三类普通单位均有明确攻击前摇，触碰本身不扣血。

### 7.2 老厨子：首个首领

候选 HP 720，普通推开/牵引效果为 15%；两个可破坏装甲部位合计结构值 80，破坏后普通位移效果提高至 30%。首领生命没有永久无敌阶段，装甲不额外减少生命伤害。全部三件权能都能直接造成有效伤害。

| 攻击 | 预警与行为 | 应对与恢复 |
| --- | --- | --- |
| 巡宴冲锋 | 1.2 秒方向预警，末 0.4 秒不再追踪；速度 9 米/秒，命中伤害 24 | 明确可偏转；结束后恢复 2 秒；星汐可在前摇改变位置 |
| 裂盏飞弹 | 0.9 秒前摇，三枚扇形飞弹，单枚伤害 14 | 可偏转，反击按原飞弹伤害结算；恢复 1.8 秒 |
| 祭桌震击 | 1.2 秒地面预警，半径 3 米，伤害 22 | 不可偏转，移动或闪避离开；恢复 2.2 秒 |

按冲锋 → 飞弹 → 震击循环起步；选择有效站位后开始预警，不在屏幕外起手。恢复期不得无提示进入下一招，至少容纳一次切换和一次正常绘制。首领动作进行时，普通疯仆不新增冲锋。

### 7.3 宴场与生成规则

短局场景为约 40 × 40 米的平坦宴场，可行走区约 32 × 32 米。中央保留组合空间，边缘以清楚的不可越界轮廓限定；桌椅和仪式装饰放在可行走区外侧，避免遮挡手势目标。

初始操作测试使用 12 / 24 / 36 个同屏敌人三档，波段候选上限分别为 12、18、24；这些是调参场景，不是性能能力结论。v0.2 开场六名饿客分两组在约 6–7.5 米处出现，保留 0.8 秒等待与地面预警；之后每约 3–4 秒从侧面补入小组，在前两次补充中分别加入疯仆、背锅人。常规补充距玩家约 7–8.5 米；场边改用相反方向，避免贴身生成。存活达到上限时暂停补充，不把额外敌人堆在生成点。

全场同时最多两个高威胁预警；首领占一个主攻击额度，首领阶段不并发普通冲锋。近身普通攻击仍按距离和个人间隔执行。压力优先通过敌种搭配、站位和频率增长，不把所有普通敌人都升级成复杂连招题。

## 9. 局外成长与斗篷记忆

### 9.1 免费基础与装配

新存档即可使用三件斗篷；教学可跳过，不通过长期货币补齐基础操作。局外解锁是永久拥有权，装备配置独立保存：每件斗篷一个变律槽，全角色一个共织槽，可选择不装备，基地免费更换。

“复原”用于教学呈现、外观与规则选项解锁；“变律”改变单件操作；“共织”深化跨斗篷作用。基地装配后下次进入战斗生效，局内不换变律。

星汐单向模式的方向约束在施法预览中显示，不能释放后偷偷交换两端。圣棘延界即使多个目标同帧接触，也只消耗一个批次。

### 9.3 后续内容规划

后续候选为绯月裂纹延伸、断骨，星汐回潮、过载连接，圣棘折界、回返，以及另外两种共织。它们不计入完整短局的首轮交付：

- 回潮用两次定时收束替代持续牵引，中间放开，不额外复制建立伤害；替代原稿与基础能力重复的“双向牵引”。
- 过载只在自然到时触发；替换、死亡、超距和阶段清理不引爆。
- 折界有一个转折点，总长度不变，按最早接触段处理；同刻接触按段序择一。
- 回返改变飞行物为逆入射方向，其他能力保留独立裁定用途。
- 传播、额外段和强化偏转都必须遵守第 6 节的来源、去重和上限。

### 9.4 残纱收支与外观

完成每个普通波段结算残纱 10；首领胜利额外 30。一场完整胜利共 60。死亡、超时或主动放弃保留已经结算的阶段残纱，不奖励未完成部分。

三变律加一个共织共需 150 残纱，示例约三次完整胜利可全部体验。这是样件的快速验证节奏，不代表正式发行的长期经济；没有重复付费装备、随机耐久和维修费用。

首个变律解锁使对应斗篷的一个记忆纹样显现；共织解锁后增加三件斗篷之间的呼应纹样。已获得外观可在基地回看，强化表现不改变战斗判定范围。“记忆”先采用清晰里程碑，不记录无法解释的隐性使用倾向。

### 11.1 三斗篷视觉规范

| 斗篷 | 轮廓/材质 | 动作/魔法线型 | 声音方向 |
| --- | --- | --- | --- |
| 绯月 | 不对称锐角、断缝、暗布与猩红内衬 | 短促甩动、分段切线、装甲碎裂 | 干脆断裂与短促布料声 |
| 星汐 | 连续弧线、双尾、深色布与紫银结点 | 延迟拖尾、端点结环、流向变化 | 收紧、共鸣、低强度流动声 |
| 圣棘 | 对称垂直轮廓、骨白与旧金几何棘纹 | 稳定张开、清晰直线、方向箭头 | 清楚落界、裁定与偏转音 |

三件共享一个玩家身体和基础骨架。差异必须在正常战斗镜头中成立；灰度查看时仍应能靠轮廓、符号与运动区分。装饰下摆不覆盖脚下危险区。

首版切换使用一套共享主动作，三件通过材质过渡、纹样与次级摆动区分。约 0.22 秒内优先表现甩动和覆盖，余摆在恢复施法后继续；不要求五个阶段分别停顿。

### 11.2 必要动画与特效

玩家动作族包含待机、移动、闪避、绘制姿态、释放、切换、受击、死亡。敌人包含移动、攻击前摇/执行/恢复、受击与死亡；背锅人增加预制装甲脱落，疯仆增加冲锋改向。

必要特效包含三种预览、切割命中、裂痕、连接/锚点、收紧、边界/箭头、裁定、偏转、装甲破损、敌方预警和死亡反馈。清楚显示效果结束，持续结构不能消失后留下误导碰撞的装饰。

视觉优先级为致命敌方预警与玩家位置 → 当前绘制与方向 → 生效结构 → 命中反馈 → 装饰。关闭强闪光、震动和装饰粒子后，判定边缘与方向仍保留。

### 11.3 声音与音乐

有效释放、无效绘制、冷却未就绪、切换、破甲、偏转分别有可区分提示。群体命中限制同类音效并发，危险提示拥有优先级；关键声音有视觉对应。

完整短局需要一段可循环战斗音乐、一段首领变化、一段简短基地氛围，以及必要动作/UI 音效；不要求配音。音乐暂停与恢复不产生突兀重启。

Krita 负责概念、纹样、UI、贴图和特效纹理；Blender 负责角色、斗篷、敌人、场景与骨骼动作；Godot 负责实际特效、动画调度、灯光与音频整合；Audacity 按需剪辑音频。首轮使用骨骼摆动与受控次级运动，复杂实时布料后续评估。

## 12. 存档、结算与异常流程

### 12.1 胜败与阶段处理顺序

每个固定物理步只处理该阶段截止时刻及之前的有效事件，完成对应攻击和伤害，再按以下顺序检查；不能用越过 8:00 的伤害反向改判：

1. 首领死亡且本局未结算：胜利，包括玩家同帧死亡或同帧达到时间上限。
2. 玩家生命归零：失败；普通波段末同帧死亡不领取刚到点的阶段奖励。
3. 战斗计时达到 8:00 且首领仍存活：超时失败。
4. 普通波段达到 2:00、4:00 或 6:00 且玩家存活：完成该阶段，结算阶段奖励并进入商店。

胜败一旦确定，本局不再处理新的伤害或重复奖励。首领胜利额外奖励与此前阶段奖励分别显示；不能在结算页再次累加已保存的阶段残纱。

### 12.2 保存范围

保存永久残纱、永久解锁、基地装配、外观里程碑、教学状态和设置。首版不支持战斗中断后继续，也不持久化本局宴屑、生命、临时强化或持续结构。

阶段完成、永久购买、装配变更与设置变更时保存。奖励以本局标识和阶段标识防重复；扣款与解锁作为一个事务提交，保存失败时不显示购买成功或吞掉货币。提供带版本号的存档、原子替换和最近一次可用备份。

崩溃后回到基地，恢复最后成功保存的永久进度；尚未成功保存的阶段奖励可能丢失。损坏时先尝试备份，无法恢复则提示选择新存档，不能无提示覆盖旧数据。

### 12.3 暂停与退出

Esc、商店与窗口失焦冻结游戏模拟时间；不把现实停留时间计入冷却、法术寿命和八分钟计时。阶段清理在进入商店前发生，与普通暂停保留现场不同。

主动放弃保留已保存的残纱与永久解锁，清空本局资源，返回基地。退出到标题或关闭程序不能被用来重复领取阶段奖励。联网、账号、云存档和跨设备同步不属于首版。

## 13. 技术与资产约定

工具方案为 Godot 4 稳定版 + GDScript、Krita、Blender、Markdown + Git，音频按需使用 Audacity。具体软件版本在开发准备阶段确认兼容性后固定，不在本文伪称已安装或验证。

Godot 渲染器暂选 Forward+，固定物理频率候选 60 Hz；若目标设备验证不适合，需记录取舍再调整。游戏规则使用物理步与模拟时间，不能随渲染帧率改变伤害或寿命。

逻辑职责分为玩家、斗篷状态与冷却、施法输入、效果实例、目标交互、敌人行为、波段/首领导演、局内构筑、永久成长与存档。已释放效果独立于当前斗篷节点生命周期；切换不能销毁所有旧斗篷效果。具体脚本与工序负责人在分工阶段确定。

资产单位采用 1 单位 = 1 米，Godot 运行世界 Y 轴向上；由 Blender 导出 GLB 时通过样件验证坐标转换、缩放和朝向。角色共用骨架及动作命名；源文件与导出文件分别保存，Godot 工程使用显式 GLB，不依赖开发者本机自动转换 `.blend`。

Krita 保留分层 `.kra`，导出 PNG；Blender 保留 `.blend`，导出 GLB；音频保留可编辑源文件及导出。先验证一个角色、一个斗篷动作、一张透明纹理、一种法术特效的完整导入路径，再批量制作。资产清单记录来源和使用范围。

性能验收建议参考机器为 Windows x64、Ryzen 5 3600 级 CPU、16 GB 内存、GTX 1660 6 GB 级 GPU、SSD，1920×1080、中档效果、目标 60 fps。这是**待确认的测试基准与目标，不是已测最低配置或性能保证**。

在参考机以 36 个普通敌人、两结构和有限飞行物运行十分钟压力场景，记录 CPU/GPU 帧时间、内存、长帧和错误。候选门槛为 95% 帧时间不高于 20 ms，99% 不高于 33.3 ms；正常游玩以约 16.7 ms 为目标。60/120 敌人的额外压力测试用于寻找上限，不作为关卡默认敌量。

云环境或 Linux 无窗口测试只能证明对应能力，不能替代 Windows 实机输入、视觉和性能验收。若参考硬件不可用，应记录未验证项，不能宣称性能通过。

| F13 | A/B | 暂停/失焦冻结模拟；恢复不误施法；商店清理与普通暂停保留现场符合不同规则 |

每轮试玩记录无效绘制比例、各斗篷使用与击杀、成功互动、受伤/死亡原因、商店购买和首领耗时。作为早期调查阈值：练习五分钟后无效绘制仍高于 15%，应优先检查吸附和范围反馈；玩家无法解释组合结果时优先改因果反馈，不直接增加特效；某件长期不用时先检查其独立价值。

初步理解测试可邀请至少三名未参与设计的试玩者，在简短教学后复述三件斗篷的差异，并完成至少一种双斗篷互动。人数用于早期发现问题，不代表统计性市场验证。

调参顺序为输入与预览 → 法则一致性 → 独立战斗能力 → 组合价值 → 敌群节奏 → 局内构筑与经济 → 视觉负载与性能。调整时更新参数表与相关验收项，不只修改实现。
