# 游戏开发学习路线

这是可调整的练习路线，不代表已经完成。先选一个引擎，用同一个小原型贯穿学习过程。

## 1. 建立最小项目

- [ ] 选择 Unity、Godot 或 Unreal 中的一个，记录引擎版本与目标平台。
- [ ] 创建空项目，确认可以运行并生成本地构建。
- [ ] 使用 Git 记录初始版本，配置引擎推荐的忽略规则。

完成标准：另一个人能按照记录打开并运行项目。

## 2. 做出一个核心循环

- [ ] 实现移动、一个交互和明确的成功或失败条件。
- [ ] 理解输入、状态、碰撞和场景切换。
- [ ] 用占位素材完成可玩的短流程，先验证玩法。

完成标准：玩家可以开始、完成或失败，然后重新开始。

## 3. 增加反馈与可靠性

- [ ] 增加必要的画面提示、音效和暂停功能。
- [ ] 检查快速重复输入、重开和退出的行为。
- [ ] 记录一个实际问题的复现步骤、原因和解决证据。

完成标准：原型运行时没有阻断核心流程的已知问题。

## 4. 构建与复盘

- [ ] 在目标平台运行打包结果，检查资源与操作提示。
- [ ] 请一位试玩者在没有口头提示的情况下体验。
- [ ] 使用[复盘模板](../templates/project-review.md)记录观察到的问题与下一步。

完成标准：有可玩的构建、操作说明和基于实际体验的复盘。

相关资料见[资源索引](../resources/README.md)。
